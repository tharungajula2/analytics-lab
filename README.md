# analytics-lab

Analytics and machine-learning studies: notebooks and small projects at the top level, and a Python credit-risk project in its own folder.

| Project | What it is | Status |
|---|---|---|
| [Credit risk PD scorecard](credit_risk_corrected/) | A PD scorecard reference with dated outcomes, train-only WoE/IV and a regularised logistic model. | Prototype (synthetic tests only) |
| [Credit risk capstone](<Capstone_NIBM_Credit Risk Modeling (PD Scorecard)/>) | The original PD model and scorecard notebooks. | Stopped (historical outputs) |
| [CartPole reinforcement learning](cartpole_corrected/) | A reinforcement-learning study on CartPole, rerun with corrections. | Prototype |
| [Antidiabetic drug forecasting](forecasting/) | Time-series forecasting of monthly prescriptions, with rolling backtests. | Prototype |
| [Bank churn](churn_corrected/) | Customer churn prediction. | Prototype (synthetic tests only) |
| [ALM and treasury analytics](ALM_Project/) | Simplified NII and LCR calculations on synthetic bank data. | Concept |
| [SFB risk lab](sfb-risk-lab/) | A small synthetic banking analytics prototype. | Prototype |
| Other notebooks | Employee retention, household classification, Twitter sentiment. | Stopped (historical outputs) |
| [Retail Credit Risk](retail-credit-risk/) | A Python project covering the retail credit-risk chain: PD scorecard, LGD, EAD, monitoring, ECL and Basel-style capital formulas. | Prototype |

`PROJECT_BLUEPRINT.md` covers methods, data flow and limitations for the top-level studies.
